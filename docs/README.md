# docs

Design records for contributors: `adr/` holds the architecture decision records,
`experiments/di-redesign/` the design of the current framework, and `explainers/` and `pr-archive/`
the supporting write-ups and past pull-request descriptions.

The user guide is the documentation site, <https://ulo-rs.vercel.app/>. For runnable code, see
[`examples/`](../examples).
