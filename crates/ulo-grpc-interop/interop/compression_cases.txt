# The four compression cases of the gRPC project's interop test descriptions, which grpc-go's
# interop client does not implement, run by `run.py` with `ulo-grpc-interop-client`, a tonic client
# with gzip enabled. The format is `cases.txt`'s.
#
# `server_compressed_streaming` asks for the first message of a reply stream compressed and the
# second uncompressed while the client accepts gzip. A reply marked `Response::uncompressed` is
# sent uncompressed whole, and no setting sends one message of a stream uncompressed apart from
# the rest, so the client's check of the second message's flag fails; its check of the first, the
# compressed one, passes before it. The per-message opt-out is built when a user asks for it.

server_compressed_unary ServerCompressedUnary
client_compressed_streaming ClientCompressedStreaming
server_compressed_streaming ServerCompressedStreaming allow F683 "response 2 asks for no compression: its compressed flag is 1" no per-message opt-out from reply compression; built when a user asks
