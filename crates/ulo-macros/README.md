# ulo-macros

The procedural macros behind `ulo`: `#[injectable]`, `#[module]`, `#[routes]`, `#[construct]`, `#[meta]`
and the enhancer-list attributes. They are re-exported from `ulo`, which is the crate to depend on;
its API docs and the `examples/` directory of the repository show each macro in use.
